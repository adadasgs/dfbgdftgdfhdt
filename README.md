# GRET TEAM Telegram Bot

## Функции
- Главное меню: 💸 Выплаты, 🛟 Поддержка, ℹ️ О нас, 👛 Кошелёк, 📤 Вывод.
- Заявка на выплату: до 2 фото, отправка администратору, кнопки одобрения и отклонения.
- Привязка TON-кошелька.
- Заявка на вывод с введённой пользователем суммой, username, кошельком и временем.
- Публикация вывода в заданную тему Telegram-группы.
- SQLite для хранения пользователей, кошельков и заявок.

## Render
Создайте Background Worker из этого репозитория.
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`

Добавьте Environment Variables:
- `BOT_TOKEN` — токен от @BotFather.
- `ADMIN_ID` — ваш числовой Telegram ID.
- `PAYOUT_GROUP_ID` — ID группы (например, `-100...`).
- `PAYOUT_TOPIC_ID` — ID темы «Выплаты» (оставьте `0`, если темы нет).
- `SUPPORT_USERNAME` — username поддержки.
- `DB_PATH` — путь к SQLite-файлу. Для сохранения данных после перезапуска используйте Persistent Disk Render и путь внутри него, например `/var/data/gret_team.sqlite3`.

Добавьте бота в группу и выдайте право отправлять сообщения. Для отправки в тему укажите её числовой `message_thread_id`.

**Важно:** бот принимает заявки и уведомляет администратора, но не отправляет TON автоматически и не проверяет блокчейн. Фактическую выплату выполняет администратор вручную. Не добавляйте токен в GitHub и не отправляйте его в чат.
